## The everyday path

| Type                         | Role                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| `SoundBus`                   | Routes play, parameter, signal, pause, and stop commands to the active manager.        |
| `SoundPlayContext`           | Describes position/following, owner, initial parameters, seed, and delay for one play. |
| `SoundPlayResult`            | Reports whether a request was admitted and returns its handle.                         |
| `SoundHandle`                | Identifies one play so you can address it later.                                       |
| `Sounds` / `SoundParameters` | Generated identifiers for this project's authored events and parameters.               |

The complete <a href={sitePath('api/sound-bus/')}>SoundBus reference</a> is the first reference chapter. It covers every public method and overload in the current source, with the defaults and return behavior that affect gameplay code.
