The **API** is the set of C# types and methods your code can use. Start with `SoundBus.Play` to play an event. Add a context when you need to choose its position or starting values, and keep its handle when you need to change or stop that play.

If those words are new, read <a href={sitePath('guides/events-plays-voices/')}>What happens when a sound plays?</a> first. All Sound Manager types below use the `DEV505.SoundManager` namespace.

## Read the signatures

A **signature** shows a member's name, input types, defaults, and return type. An **overload** is another version of the same method with different inputs. `bool` means true or false; `out` returns an additional value through an argument; `in` passes a value for read-only use. You do not normally need to type `in` at the call site.

Reference blocks list declared members, not complete scripts to attach to an object. Complete components are labeled separately. Fields' starting values and units appear in the accompanying tables. The signature blocks are extracted from the documented source revision; the explanation gives the behavior and constraints.

Use playback APIs on Unity's main thread—for example, from a component's Start, Update, button callback, or animation event. Do not call them from a worker task.
