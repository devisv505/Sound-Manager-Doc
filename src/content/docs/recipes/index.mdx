Choose the interaction you want to add. Each recipe explains what to put in the scene, which fields to assign, how to try it, and how it cleans up afterward. The complete scripts use generated `Sounds.*` keys and are checked against the Unity project.

New to Unity or this asset? Start with <a href={sitePath('getting-started/')}>Your first sound</a>. For the models, full HUD, and gameplay behind these examples, explore the <a href={sitePath('demos/')}>ten demo walkthroughs</a>.

Recipes are small integrations. Some share the same checked component so you can study one idea at a time without maintaining different versions of the code. Test them in a separate scene with the listed events registered; the full demo scenes already have their own controllers.
