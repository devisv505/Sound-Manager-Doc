## From a spark to a sound.

The graph handles ignition, the crackling loop, and the extinguish cue. Your code asks it to begin—and tells it when to end.

```csharp title="Play by key · excerpt"
var result = SoundBus.Play(Sounds.Campfire, transform);
if (result.Accepted)
    fire = result.Handle;

// Later, when the player puts the fire out:
SoundBus.Stop(fire, fade: 0.15f);
```
